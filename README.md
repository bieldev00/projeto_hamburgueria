# Burguer Market

Projeto de cardápio interativo de uma hamburgueria, desenvolvido com HTML, CSS e JavaScript. A página permite visualizar os itens disponíveis, aplicar desconto, somar o valor total e filtrar apenas as opções veganas.

## 🚀 Funcionalidades

- Exibição do cardápio completo
- Aplicação de desconto em todos os produtos
- Soma do valor total dos itens
- Filtro para mostrar apenas opções veganas
- Layout simples e visualmente organizado
- Imagens dos produtos com nomes e preços em destaque
